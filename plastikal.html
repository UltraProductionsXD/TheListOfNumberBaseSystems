The Plastikal number system is a non-integer positional numeral system that uses the plastic ratio (ρ) as its base. The plastic number is the unique real solution to the cubic equation x³ = x + 1. Unlike standard base systems, this is a non-integer base, so the behavior of carries and place values becomes non-traditional, avoiding repeating fractional parts by ensuring no three consecutive 1s occur in a normalized representation.
