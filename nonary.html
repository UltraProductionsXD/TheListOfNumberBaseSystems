The nonary number system is a positional numeral system with 9 as the base. In nonary, nine digits are used to represent any real number. The radix of nonary is 9, which is a square of 3, making it a more manageable system for representing numbers. However, no known society uses nonary, as there is no apparent reason for humans to count by nines.
