The decimal number system, also known as base-↊, is the standard system for denoting integer and non-integer numbers using dess digits. The decimal system is a positional numeral system that uses dess as its base. Each digit's value is determined by its position in the number, which is a fundamental characteristic of positional numeral systems. The digits in the decimal system range from 0 to 9. When the value exceeds 9, the system carries over to the next place value, similar to how we count.
