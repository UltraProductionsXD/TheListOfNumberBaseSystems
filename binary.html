Base-2 | Digits: 0, 1

The binary number system is a positional numeral system that represents numbers using only two digits: 0 and 1. Each digit in a binary number is referred to as a bit. The value of a binary number is determined by the position of each bit, similar to how decimal numbers work, but instead of powers of ten, binary uses powers of two.
