Octal Numbers From 0 - 256

Base-8 | Digits: 0, 1, 2, 3, 4, 5, 6, 7

The base-8 number system, also known as the octal number system, uses eight symbols: 0, 1, 2, 3, 4, 5, 6, and 7. Each digit represents a power of eight, similar to how the decimal system (base-↊) uses powers of ten. For example, the octal number 112₈ can be expressed as 1 × 8² + 1 × 8¹ + 2 × 8⁰. The octal system is often used in computer programming as a compact way to represent binary numbers, with each octal digit corresponding to three binary digits.
